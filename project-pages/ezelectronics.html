EZElectronics

A web app for electronics shops. Managers add products and confirm sales, customers buy and leave reviews, and admins look after the data. I led the team that built and tested the server.

Role
Team lead, 4-person international team
When
2024
Context
Software Engineering, Politecnico di Torino
Stack
TypeScript, Node.js, Express, SQLite, Jest, React
  • Code on GitHub

Overview

First we wrote the requirements and the design: context, use-case, glossary and deployment diagrams, and mock-ups of the screens. Then we built the server against the API spec we were given, so the React client would work without changes.

The server is TypeScript on Express, split into routers, controllers and data-access objects over SQLite. Login uses Passport sessions, and express-validator checks every request.

Testing

We wrote unit, integration and API tests with Jest and Supertest. At the end we had 403 tests in 17 suites, all passing, with 90% statement coverage and 93% function coverage.
