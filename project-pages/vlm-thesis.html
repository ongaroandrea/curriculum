Evaluating Open-Weight Vision-Language Models for Difference Identification in Rendered Images

Towards automated feedback in computer graphics education. I wanted to know whether a vision-language model running on a local machine can look at a student's render, compare it with a reference, and say what's off.

Why

Students in computer graphics courses learn by comparing their renders with a reference image. Teachers can't give detailed feedback on every one of them. If an open model can do part of that work on a university workstation, nothing has to be sent to a cloud service.

What I did

  • Built a rendering pipeline that changes one visual parameter at a time. The images it produces form a benchmark for telling renders apart from real photographs.
  • Ran six open-weight vision-language models through Ollama on a local workstation and looked at where each one fails, across architectures and model sizes.
  • Tried prompt engineering and fine-tuning to make the answers more reliable.
  • Wrote guidelines for using these models in computer graphics courses.
  • Built website to run the project for the university's course
